   <h3>Metrics</h3>
   <p>PAR-2 is the mean cost of the runs. A run that finishes counts as the calls it used. A run that fails counts as twice the cap.</p>
   <p>The main metric is Mean epochs.</p>
   <p>An archived score is the average of the runs that finished under the cap. A run that hit the cap is a failure and is left out of that average.</p>
   <ul>
   <li>Mean epochs</li>
   <li>Median epochs</li>
   <li>Mean energy RMSE</li>
   <li>Median energy RMSE</li>
   <li>Mean force RMSE</li>
   <li>Median force RMSE</li>
   <li>Failed runs</li>
   </ul>
   <p>Select a column heading to sort the table.</p>
   <p>Rows are ranked by cost inside each method family and on one overall table. A run that used fewer starts than the full set, or that is not the standard method, stays off the table.</p>
   <p>A performance profile compares at least two codes. This problem has fewer, so that plot is omitted.</p>
