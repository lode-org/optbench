   <h2>Pt heptamer island</h2>
   <dl class="bench-rule">
   <dt>Stop</dt><dd>L2 norm of the force at or below 0.001 eV/Angstrom</dd>
   <dt>Goal</dt><dd>27 connected saddles below 1.5 eV</dd>
   <dt>Potential</dt><dd>morse</dd>
   <dt>v2</dt><dd>par2-bootstrap</dd>
   <dt>v2 cost</dt><dd>one displacement search: the climb plus the two endpoint minimizations</dd>
   </dl>
   <p class="bench-aside">A 2-search SoftSaddle batch stays off this rank. The April 2019 adaptive_HSphere-lbfgs-davidson-sm50 entry records 423491.1 force calls.</p>
   <p>Rows are ranked by cost inside each method family and on one overall table. A run short of the full set, or a run that is not the stock method, stays off the table.</p>
   <p class="bench-gaps">Eon rows are not yet on the harness counter. A run short of the full set, or a run that is not the stock method, stays off the ranked table.</p>
