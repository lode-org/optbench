Scores for geometry optimizers, saddle searches, and global optimization.

#+INCLUDE: "../include/overview.org"

Chill, Stevenson, Ruehle, Shang, Xiao, Farrell, Wales, and Henkelman set the 2014 problems in J. Chem. Theory Comput. 2014, 10, 5476-5482 ([[https://doi.org/10.1021/ct5008718][doi:10.1021/ct5008718]]).
The tutorial page scores two optimizers on 100 starts from a fresh clone.

When an archived entry counts its failed runs, each counts as twice the cap, and the row ranks on that PAR-2.

* Contact

Questions, bug reports, and requests for a new code or problem go to the GitHub issue tracker.
The tracker is https://github.com/lode-org/optbench/issues.
It is the one place to ask about this repository and the site.
A report about a score helps most when it names the problem id and the template id.
It should also attach the =benchmark.dat= that the run wrote.
A report about a client build also needs the version line that the client prints.

* Citation

Cite the repository and the commit you used.
Read the entry at [[https://github.com/lode-org/optbench/blob/main/CITATION.cff][CITATION.cff]].
For the 2014 problems named in the synopsis on this page, cite that paper as well.
The request covers the problems the synopsis already ties to the paper.
Later suites stay outside that request.
Surnames, the journal abbreviation, the year, the volume, and the pages in the entry match the synopsis.
Given names, the article title, and the issue number sit outside the synopsis.
The entry records those extra fields without a publisher check.
The entry does not set a license key.
The Massachusetts Institute of Technology (MIT) License already lives in [[https://github.com/lode-org/optbench/blob/main/LICENSE][LICENSE]].
A score taken from the board also names its code, its version, and its template id.
