OptBench compares geometry optimizers, saddle searches, and global optimization.

Chill, Stevenson, Ruehle, Shang, Xiao, Farrell, Wales, and Henkelman
set the problems in J. Chem. Theory Comput. 2014, 10, 5476-5482
([[https://doi.org/10.1021/ct5008718][doi:10.1021/ct5008718]]).

The score on each problem they set is PAR-2, the mean cost of the runs.
A finished run counts as the calls it used, and a failed run counts as twice the cap.
An archived row keeps the average it published, which leaves failed runs out.

#+INCLUDE: "../include/overview.org"

The board page lists the lowest-cost row of every problem.
The commands that write a new =benchmark.dat= are on the Run a score page.

* Contact

Questions, bug reports, and requests for a new code or problem go to the GitHub issue tracker.
The tracker is https://github.com/lode-org/optbench/issues.
It is the one place to ask about this repository and the site.
A report about a score helps most when it names the problem id and the template id.
It should also attach the =benchmark.dat= that the run wrote.
A report about a client build also needs the version line that the client prints.
