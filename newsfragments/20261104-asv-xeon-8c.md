`results/asv/xeon-8c` now stores the asv results of the 8-core Xeon machine, which sat in the host-named results folder.
The machine record and every result file call that machine `xeon-8c`.
Four asv writers read the machine record from that folder and write new results to it.
They are `eon_svn`, `noise_asv`, `pele_asv` and `sella_loweig`.
The move leaves every recorded timing as it was.
