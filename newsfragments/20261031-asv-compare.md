Pull-request timings are one interleaved `asv run` of the two commits, driven by Snakemake, on a single runner. The commits are read from a hash file. Rounds are interleaved. The run does not pass `--quick`. A timing row fails only when the sample test finds a difference between the commits, and a track change fails at any size. A missing track value fails the job. The comparison text stays when the decision fails. A separate workflow posts that text for a pull request from this repository or from a fork. The report is quoted inside a fence. The benchmark workflow cannot write pull-request comments.
